## Tujuan Praktikum

- Memahami dasar pengembangan aplikasi mobile menggunakan Flutter.
- Mempelajari penerapan konsep Refactoring Code.
- Memahami teknik Extract Widget untuk memisahkan komponen UI.
- Membuat custom widget yang reusable.
- Meningkatkan keterampilan dalam menyusun kode yang modular, rapi, dan mudah dipelihara.

## Penjelasan Singkat

- Menggunakan widget modular dan reusable, seperti `ProfileAvatar`, `ProfileName`, `ProfileRole`, dan `ProfileInfoCard`.
- Menampilkan halaman profil yang berisi avatar, nama pengguna, role, dan kartu informasi.
- Menerapkan konsep **Refactoring Code** untuk merapikan dan meningkatkan struktur kode.
- Menerapkan **Extract Widget** untuk memisahkan komponen UI menjadi file tersendiri.
- Membuat struktur kode lebih modular, terorganisir, dan mudah dipelihara.

## Struktur File

- `main.dart` — Entry point dan konfigurasi utama aplikasi Flutter.
- `profile_page.dart` — Menampilkan serta menyusun halaman profil.
- `profile_widgets.dart` — Berisi kumpulan custom widget yang reusable.

- Berhasil membuat aplikasi halaman profil sederhana menggunakan Flutter.
- Berhasil memisahkan komponen UI menjadi beberapa custom widget.
- Berhasil menerapkan konsep Refactoring Code dan Extract Widget.
- Menghasilkan struktur kode yang lebih terorganisir, mudah dibaca, dan dapat dikembangkan kembali.
- Memahami cara menggunakan widget reusable untuk meningkatkan efisiensi pengembangan aplikasi.

## Kesimpulan

Praktikum pertemuan 5 memberikan pemahaman mengenai pembuatan halaman profil menggunakan Flutter dengan menerapkan Refactoring Code dan Extract Widget. Dengan memisahkan komponen UI menjadi widget yang reusable, kode menjadi lebih modular, rapi, dan mudah dipelihara.
