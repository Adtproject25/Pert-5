## Penjelasan Singkat

- Menggunakan widget modular dan reusable, seperti `ProfileAvatar`, `ProfileName`, `ProfileRole`, dan `ProfileInfoCard`.
- Menampilkan halaman profil yang berisi avatar, nama pengguna, role, dan kartu informasi.
- Menerapkan konsep **Refactoring Code** untuk merapikan dan meningkatkan struktur kode.
- Menerapkan **Extract Widget** untuk memisahkan komponen UI menjadi file tersendiri.
- Membuat struktur kode lebih modular, terorganisir, dan mudah dipelihara.

## Struktur File

- `main.dart` — Entry point dan konfigurasi utama aplikasi Flutter.
- `profile_page.dart` — Menampilkan serta menyusun halaman profil.
- `profile_widgets.dart` — Berisi kumpulan custom widget yang reusable.
